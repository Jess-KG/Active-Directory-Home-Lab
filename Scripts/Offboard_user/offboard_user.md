# Offboarding a user

## Overview
This project helps automate the offboarding of a user from the company. This script will input username and will disable the account, remove groups, and move to the Disabled OU.

## Problem Scenario
HR has asked you to offboard an employee.
* Disable the account
* Move to Disabled OU
* Remove from all groups 

## Refer to the script.ps1 file for the solution.
