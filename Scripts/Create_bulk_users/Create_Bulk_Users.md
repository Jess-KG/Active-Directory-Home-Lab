# Bulk create users from CSV

## Overview
This project helps automate the creation of accounts, especially when multiple people are to be onboarded.
The user details are inputted from a csv file. I have attached a sample csv file that can be used for testing purposes.

## Problem Scenario
HR has sent you a csv file that contains firstname, lastname and OU (department name) of users. Your task is to onboard everyone.
* Create new user accounts
* Add to an appropriate OU
* Assign a temporary password
* Enable Accounts
