# Creating a Single User

## Overview
This project aims to create a simple powershell script that can be used to add a single user to the active directory.

## Problem Scenario
HR has sent you the details of a newly hired person. Your task is to onboard that person.
* Create new user account
* Add him to an appropriate OU
* Add him to an appropriate Group
* Assign a temporary password
* Enable Account
